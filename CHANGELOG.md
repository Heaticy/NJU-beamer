# Changelog

All notable changes to NJU-Beamer are documented in this file.

## v0.1.0 - 2026-11-11

- Four theme entries on one shared implementation: `nju` (campus background), `nju-plain`, `nju-report` and `nju-showcase` (gradient cover, navigational section pages, progress footline).
- Nanjing University purple palette (`#5C0F56`, CMYK 50/100/0/40) with a gold accent.
- Vector runtime assets generated from `assets-src/nju-assets.tex`: emblem, name lockup, motto, North Building skyline, ribbon background and the slide background.
- Shared components: `njuquote*` callouts, `\NJUstat`, `\NJUmark`, `\NJUchip`, `\NJUsteps`, `\NJUmeter`, `Code`, `Figure`, `Table`.
- Practice deck `Midterm-Defense-LiAnode` in the `nju` and `nju-showcase` styles.
